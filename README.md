# EPStudy V6

V6 is a static GitHub Pages bundle.

- `index.html` is the Normal workspace.
- `simple.html` is the Simple workspace.
- `shared/` contains assets and data used by multiple workspaces.
- `versions/v3/` and `versions/simple/` are compatibility redirects for old links.
- `extension/` contains the Chrome/Edge extension source.

This repository is the standalone V6 app. The active app files live at the root so GitHub Pages can serve Normal and Simple directly.
