# EPStudy V6

V6 is a static GitHub Pages bundle.

- `index.html` redirects to Normal mode by default.
- `shared/` contains assets and data used by multiple workspaces.
- `versions/v3/` contains the Normal workspace.
- `versions/simple/` contains the Simple workspace.
- `extension/` contains the Chrome/Edge extension source.

If you want a repository that contains only V6, initialize git from this `V6` folder instead of the parent folder.
